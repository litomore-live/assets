# 直播间封面设计约定

角色参考：[像素角色原图](../../characters/pixel-streamer/source.png)。标题和装饰随直播主题调整，保留这套角色与视觉风格。

## 比例与构图

- **保持人物原始比例**：锁定参考图的脸型、头身比和姿势；人物及整图只能等比例缩放，不得横向拉宽或纵向压扁。编辑背景时尽量保持人物本身不变。必须以最初透明角色图作为主要身份与比例参考，不沿用多轮重绘后的角色作为比例基准。
- 输出尺寸不符时，通过等比缩放、裁切或扩展背景适配；不得用强制宽高的方式拉伸（例如 ImageMagick 的 `-resize 宽x高!`）。导出时核对横纵缩放系数一致，并与角色参考图目视比对。
- 生成一张 **2048 × 1536（4:3）主图**，再从正中裁出 **1920 × 1080（16:9）**：左右各裁 64、上下各裁 228 像素。两个版本使用同一张图。
- 标题、LIVE 标识、角色的头部、脸和耳机，以及主要图形，都放在 **x = 64～1984、y = 228～1308** 的居中裁切范围内，保持完整并尽量留出视觉余量。
- 4:3 是一张完整的封面。上下使用**更大、更密、成组叠放**的像素窗口、文件夹、代码卡片、键盘、手柄和节点，组成贯穿画面宽度的装饰组合；用棋盘格、轨迹、爱心和星星填补组间空隙，不能只排一行小图标或留下大块空白。
- 上下装饰可以在 16:9 中被裁掉；不能依赖这些装饰传递重要信息。装饰保持轻重层次，避免遮挡标题或角色。较大的窗口、键盘等尽量完整放进被裁区域，避免 16:9 边缘留下半截大图形。

## 风格与文案

- e-girl 多巴胺配色、日式电子游戏像素 anime 风；保留方形像素、阶梯轮廓、深色描边和错位阴影。
- 配色以浅底 `#fff8ff`、亮粉 `#ff5bbd`、紫色 `#7745f5`、深紫 `#28163e`、薄荷绿 `#a0f6e5` 为主，少量黄色点缀。
- 沿用紫发、粉色猫图案耳机、粉色与薄荷绿发夹、爱心项链、紫色宽松毛衣的角色；默认保持开心、托腮的形象。
- 左侧大标题，右侧角色，配少量与主题相关的像素图形。默认标题为「开源项目维护」，分成「开源项目」「维护」两行。
- 除主题标题与 LIVE 外不额外堆文案；代码窗口可用抽象彩色条和标点，不放难以辨认的小字。直播封面不使用语音朗读或声音选择主题。

## 导出与检查

- 同目录保存 4:3 和 16:9 的 **PNG、JPG**；JPG 使用质量 95、4:4:4 色度采样。PNG 保留用于后续编辑。
- 正式目录只保留选定的最终版本：4:3、16:9 各一份 PNG 和 JPG。中间版本使用临时目录，确认后清理；文件名不堆叠版本后缀。提示词只保留一份最终规格，放在 `../../prompts/`，并同步更新索引。
- 必须对照原角色目视检查**脸宽与脸长、额头到下巴、颈部和躯干长度、头部与肩膀的关系**，不能仅凭整张画布宽高比一致就判断人物比例正确。再检查实际 16:9 裁切、中文与关键图形完整性，以及 4:3 的装饰密度。
